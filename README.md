# AegisSim

AegisSim is a distributed real-time sensor simulation and tracking platform designed to demonstrate software engineering concepts including distributed systems, sensor data processing, tracking algorithms, microservices, automated testing, containerization, and hardware/software integration.

## Planned Technologies

- Java
- Spring Boot
- Maven
- Python
- React
- TypeScript
- PostgreSQL
- Docker
- Linux
- JUnit
- GitHub Actions
- Ansible
